### Problem Description

**Task:** Given a double value d, typecast it to an integer value and print it.

#### Examples

##### Example 1

- **Input:**
```text
d = 10.23
```
- **Output:**
```text
10
```
- **Explanation:** The integer value of 10.23 is 10

##### Example 2

- **Input:**
```text
d = 19.1
```
- **Output:**
```text
19
```
