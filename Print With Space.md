## 01. Print With Space

The problem can be found at the following link: [Question Link](https://www.geeksforgeeks.org/problems/print-with-space/1?selectedLang=python3)

### Problem Description

**Task:** Given two strings a and b, print them on the same line with a single space between them. Print a newline after the output.

#### Examples

##### Example 1

- **Input:**
```text
a = "Hello", b = "World"
```
- **Output:**
```text
Hello World
```
- **Explanation:** a and b are printed in a single line and a space separates them.

##### Example 2

- **Input:**
```text
a = "Geeks", b = "for"
```
- **Output:**
```text
Geeks for
```
- **Explanation:** a and b are printed in a single line and a space separates them.

- **Expected Auxiliary Space Complexity:** O(1)
